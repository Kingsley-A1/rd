# RAY DYNASTY — Artist Electronic Press Kit

Responsive, one-page static HTML artist website concept, prepared by Bespoke Technologies.

## Preview locally
Open `index.html` in a browser. No build command or framework is required. The site uses the local files in `assets/` and optionally loads display fonts from Google Fonts. It works without the external fonts using fallbacks.

## Deploy
Upload the whole folder (including `assets/`) to any static hosting provider, e.g. Netlify, Vercel, Cloudflare Pages, cPanel, GitHub Pages.

## What is included
- Full-screen artist introduction with supplied official portrait
- Artist story, background and musical influences
- “MISDEMEANOUR” upcoming release feature
- Full press biography with copy button
- Downloadable supplied press photo and promotional artwork
- Instagram, TikTok and Facebook links as supplied
- Mobile-first responsive layout, accessible landmarks, reduced-motion support

## Pre-launch checks with artist
1. Confirm approval to publish the supplied photos, bio and EPK.
2. Confirm the 30 October 2026 release date; it is taken from supplied promotional art, while the supplied biography described the song as already released. The website correctly labels it *upcoming* as of 28 October 2026. Update this section once release links are available.
3. Ask for booking/management email (none supplied, so the site currently directs enquiries to Instagram).
4. Obtain official Spotify, Apple Music, YouTube / music links before adding listen buttons. No unverified platforms have been invented.
5. If a production domain is assigned, set canonical URL and absolute `og:image` URL for optimal link previews, and update copyright/legal information if needed.
6. Confirm official spelling of full name: supplied bio says **Jaboro Treasure**.

## Assets
Photographs and artwork were provided by the client/prospect, not AI-generated. Do not redistribute publicly without appropriate permission.
